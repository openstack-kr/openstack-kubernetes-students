부록 B. 수동 명령과 설치 자료
==========================================================================================

이 부록의 목적
------------------------------------------------------------------------------------------

다른 사람이 같은 구성을 다시 만들려면 명령뿐 아니라 그 명령이 읽는 설정 파일도 필요합니다.
이 부록은 팀에서 받아야 할 파일과 실행 기록을 정리합니다.
파일 이름이 같더라도 내용이 바뀔 수 있으므로 작성 시점이나 Git 커밋을 함께 보관합니다.


설치 명령은 단계별 ``# MANUAL n`` 표식부터 집계합니다. 상태 확인용 ``# NOTE n`` 명령,
변수 파일 편집과 실패 후 원인을 조사한 명령은 따로 구분합니다.
0단계에서 표식 전에 실행한 ``apt-get`` 은 설치 명령에 포함했습니다.
NTP 보정 중 호스트 시계가 약 366초 바뀌어 해당 구간의 소요 시간은 단순한 시각 차이로 계산하기 어렵습니다.

다시 구축할 때 필요한 자료
------------------------------------------------------------------------------------------

* **0~1단계** — 도구 버전, 클라우드 이미지 체크섬, Terraform 설정 및 cloud-init 파일
* **2~3단계** — 최종 인벤토리, Ansible 플레이북, Kubespray 변수 및 설치 로그
* **4단계** — 노드 레이블, StorageClass 설정, PVC와 테스트 파드 매니페스트
* **5단계** — 릴리스별 values 파일 11개, 적용 순서와 차트 버전
* **6단계** — 클라이언트 파드 매니페스트와 테스트 자원의 생성·조회·정리 기록

팀 기록에 전체 파일이나 명령이 없는 항목은 서버 원본과 대조해야 합니다. 자동화 키트의 명령 수와 소요 시간은
깨끗한 환경에서 키트를 실행한 뒤 별도로 집계합니다.

7단계 추가 자료와 최종 상태
------------------------------------------------------------------------------------------

* ``~/openinfra-lab-kit/openstack-helm/values-horizon.yaml``: Horizon 설정
* ``~/openinfra-lab-kit/openstack-helm/values-neutron-vxlan4790.yaml``: Neutron 포트 변경 설정
* CirrOS 이미지 원본·체크섬, 생성한 플레이버와 네트워크의 실제 설정 및 생성 기록
* CLI 인스턴스 생성 명령, Horizon 화면 결과와 콘솔·DHCP 로그
* ``~/logs/baseline-1104/``: 변경 후 상태 기록
* ``backup-final-1104.tar.gz``: 추가·변경 설정을 포함한다고 기록된 백업

파일 위치는 당시 Ubuntu 호스트 기준입니다. PDF에 YAML 전문이 실려 있지 않아
원본을 별도로 확보해야 합니다. 백업의 전체 체크섬도 원본에서 확인합니다.
공개 자료에는 비밀번호·토큰·개인키와 실제 공인 서버 주소를 포함하지 않습니다.

11월 2일 상태와 11월 4일 상태는 Horizon, Neutron 리비전, 인스턴스 수가 다릅니다.
명령 수와 소요 시간도 이 변경을 구분해 집계합니다. 7단계 수동 명령 수는 원본에서
집계가 완료되지 않았으므로 임의의 숫자를 채우지 않습니다.

최종 PDF에 추가된 화면 실습 안내
------------------------------------------------------------------------------------------

``구축내용.pdf`` 21~22쪽에는 CirrOS 0.6.2 x86_64 이미지 다운로드·업로드,
``m1.tiny`` 생성(vCPU 1개, RAM 512 MB, 루트 디스크 1 GB),
``demo-net`` 과 ``demo-subnet`` 생성(10.10.10.0/24), Horizon 인스턴스 시작
절차가 추가됐습니다. 자세한 방법은 :doc:`ch7_horizon` 을 따릅니다.
이미지 체크섬과 최종 Helm values 전문은 여전히 별도 확보 대상입니다.
