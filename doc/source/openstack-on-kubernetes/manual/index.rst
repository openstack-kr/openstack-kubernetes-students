수동구축
==============================================

처음 시작하는 분께
----------------------------

이 실습에서는 먼저 Linux 서버(물리 서버) 안에 가상 머신(Virtual Machine, VM) 네 대를 만듭니다. 
VM은 물리 장비를 추가하지 않고도 운영체제를 따로 실행할 수 있는 가상 컴퓨터입니다.
이 네 대를 하나의 Kubernetes 클러스터로 묶은 뒤, 그 위에 OpenStack을 설치합니다.
여기서 클러스터는 여러 서버를 함께 관리하는 하나의 시스템을 뜻합니다.
마지막에는 직접 이미지와 네트워크를 만들어 설치가 잘됐는지 확인합니다.

먼저 Kubernetes를 운영할 VM을 만들고, 나중에 그 안에 OpenStack을 설치한다는 순서를 구분해야 합니다. 
OpenStack 설치가 끝난 뒤 사용자가 만드는 인스턴스도 VM이지만, 처음 만든 네 대의 Kubernetes 노드 VM과는 
역할이 다릅니다.

.. code-block:: text

   Windows PC: 문서 편집, 서버 접속
       ↓ SSH
   Ubuntu 호스트: 구축 도구 실행, 노드 VM 관리
       ├─ cp: Kubernetes 관리
       ├─ ctrl-worker: OpenStack 제어 서비스
       ├─ compute-1: OpenStack 컴퓨트 서비스
       └─ compute-2: OpenStack 컴퓨트 서비스

시작 전에 팀에서 다음 자료를 받아야 합니다.

* Terraform 설정과 cloud-init 템플릿: VM과 처음 로그인할 계정을 만드는 파일
* Ansible 설정과 플레이북: 네 VM에 동일한 설정을 적용하는 파일
* 당시 배포에 사용한 Helm values 11개: 서비스별 환경 설정 파일
* 검증용 osc 파드 매니페스트와 인증 설정: OpenStack 명령을 실행할 환경

인증 정보는 팀의 비공개 경로로 전달받습니다.
새 자동화 코드의 파일이 과거 수동 구축 파일과 같다고 가정하지 않습니다.
자동화 절차는 :doc:`../kit/index` 에서 설명합니다.

명령을 입력하는 위치
------------------------------------------------------------------------------------------

Windows PC에서 VS Code 터미널을 열고 다음 명령으로 Ubuntu 호스트에 접속합니다.
``서버주소`` 는 팀에서 받은 실제 주소로 바꾸고, 계정이 다르면 ``lab`` 도 바꿉니다.

.. code-block:: powershell

   ssh lab@서버주소

접속한 다음 아래 명령으로 현재 서버와 계정을 확인합니다.

.. code-block:: bash

   hostname
   whoami
   pwd

``hostname`` 은 서버 이름, ``whoami`` 는 로그인 계정, ``pwd`` 는 현재 폴더를 표시합니다.
이후 Bash 명령은 별도 안내가 없으면 Ubuntu 호스트에서 실행합니다.
노드 VM이나 파드 내부로 들어가는 단계에서는 실행 위치를 다시 표시합니다.
접속을 종료하는 ``exit`` 는 한 단계 바깥의 터미널로 돌아가는 명령입니다.

파일과 코드 블록 읽기
------------------------------------------------------------------------------------------

* ``bash`` 와 ``sh`` 블록은 안내한 터미널에서 실행하는 명령입니다.
* ``yaml`` 과 ``ini`` 블록은 명령이 아니라 지정한 파일에 저장하는 설정입니다.
* ``~`` 는 현재 로그인한 계정의 홈 폴더입니다. 호스트의 ``lab`` 과 VM의 ``kit`` 은
  홈 폴더가 다르므로 경로를 확인합니다.
* 명령 끝의 ``\`` 는 다음 줄까지 같은 명령이 이어진다는 표시입니다.
  여러 줄로 된 명령은 한 묶음으로 복사합니다.
* ``sudo`` 는 관리자 권한으로 명령을 실행하며, ``#`` 뒤의 내용은 설명용 주석입니다.
* 결과를 확인한 뒤 다음 블록으로 이동합니다. 오류가 나면 이후 설치를 계속하지 않습니다.
