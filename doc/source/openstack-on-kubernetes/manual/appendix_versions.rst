부록 A. 사용한 버전
==========================================================================================

버전 표를 사용하는 방법
------------------------------------------------------------------------------------------

같은 이름의 도구도 버전에 따라 설정 문법과 동작이 달라질 수 있습니다.
아래 표는 제공된 수동 구축 기록의 버전 목록이며 최신 버전을 추천하는 표가 아닙니다.
다시 구축할 때는 설치한 버전과 기록값을 비교하고, 달라진 항목을 따로 적습니다.
컨테이너 이미지 태그는 이름표이고 digest는 특정 이미지 내용을 가리키는 값입니다.
아래의 미완료 항목 역시 당시 기록의 상태이며 현재 자동화 코드와 구분합니다.


아래는 팀이 수동 구축에 사용한 값입니다. OpenStack 릴리스와 개별 Helm 차트는 버전 표기가 다릅니다.

7단계 추가 버전과 배포 이력
------------------------------------------------------------------------------------------

Horizon 차트는 ``2025.2.10+c665eedfa`` 이며 추가 설치 직후 리비전은 1입니다.
기존 11개에 Horizon을 더해 릴리스는 12개가 되었습니다. Neutron은 VXLAN 포트
변경 후 리비전 3이었습니다. 이 번호는 Neutron 차트 버전이 바뀌었다는 뜻이 아닙니다.
인스턴스 부팅 시험에는 CirrOS 0.6.2 이미지를 사용했습니다.

이미지 다이제스트
------------------------------------------------------------------------------------------

배포 전 렌더링 결과에서는 이미지 19종을 확인했고, 배포 후에는 실행 중인 이미지의 다이제스트를
``~/logs/image-digests-1101.txt`` 에 17줄로 기록했습니다. 집계 대상이 달라 두 수치를 직접 비교하기 어렵습니다.
``latest`` 계열 태그 5종을 배포 설정에 다이제스트로 고정하는 작업은 남아 있습니다.
위 이미지 개수와 다이제스트 기록은 Horizon 추가 전인 11월 1일 기준입니다.
11월 4일 최종 이미지 목록에는 Horizon도 포함해 다시 수집해야 하며, PDF에는
최종 전체 목록과 고정 완료 결과가 없습니다.
