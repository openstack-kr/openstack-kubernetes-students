개요
====

무엇을 만드는가
---------------

전체 구조는 "건물 안의 방 안에 가구를 놓는 것"처럼 층층이 쌓여 있습니다.

.. code:: text

   빌린 서버 (베어메탈 1대)
    └─ VM 4대 (libvirt/KVM)                           ← 1단계
        └─ 노드 사전 설정 (Ansible)                    ← 2단계
            └─ Kubernetes 클러스터 (Kubespray)         ← 3단계
                └─ 선행 요소 (스토리지, 레이블 등)      ← 4단계
                    └─ OpenStack (OpenStack-Helm)     ← 5단계
                        └─ 검증                        ← 6단계

- 서버 점검과 도구 설치는 0단계입니다.
- 각 층은 아래 층이 정상이어야 올릴 수 있으므로, **번호 순서대로** 진행하고 단계마다 확인한 뒤 넘어갑니다.

+------+-------------------------------+------------------------------+----------------------------------+---------+
| 2    | 노드 사전 설정                | Ansible                      | `2단계 <ch2_ansible.md>`__       | 작성됨  |
+------+-------------------------------+------------------------------+----------------------------------+---------+
| 3    | Kubernetes 구축               | Kubespray                    | `3단계 <ch3_kubernetes.md>`__    | 작성됨  |
+------+-------------------------------+------------------------------+----------------------------------+---------+

+------+-------------------------------+------------------------------+----------------------------------+---------+

키트가 하는 일과 하지 않는 일
-----------------------------

**하는 일**

- 서버가 구축에 적합한지 점검하고 필요한 도구를 정해진 버전으로 설치 (0단계)
- 1~6단계의 실행, 단계 간 연결, 단계별 로그와 소요 시간 기록
- 실패했을 때 어느 단계의 어떤 항목인지, 가능한 원인과 로그 위치를 알려 줌

**하지 않는 일**

- 평가(성공률, 결과 일관성 측정)를 자동화하지 않습니다.
- 실패 원인을 분석해 설정을 고치고 이어서 진행하는 자동 복구는 하지 않습니다.
- 사용자 VM 생성은 다루지 않습니다.

실행 방식 (키트 완성 후)
------------------------

================== ===========================================
명령               동작
================== ===========================================
``make preflight`` 0단계 점검만 실행
``make install``   0단계 점검 + 도구 설치까지
``make up``        0단계 포함 전체 구축 (설치된 도구는 건너뜀)
``make stage-N``   N단계만 실행 (N = 0~6)
``make verify``    6단계 검증만 실행
``make destroy``   구축한 VM 등 초기화
================== ===========================================

이 가이드를 읽는 법
-------------------

각 장은 같은 구성을 따릅니다.

1. 이 단계가 하는 일
2. 선행 조건
3. 키트로 실행하기
4. 단계별로 따라 하기 (수동 절차 설명)
5. 기대 결과
6. 확인 방법
7. 이 단계에서 겪은 오류와 주의사항
8. 문서 재현 검토
9. 막혔을 때 (문제 해결 장 안내)

글 중의 상자는 다음을 뜻합니다.

.. note::

   **참고**: 알아 두면 좋은 설명이나 이 환경에서 관찰한 내용입니다.

.. warning::

   **주의**: 지나치면 실패하거나 보안, 재현성에 영향을 주는 내용입니다. 꼭 읽으세요.

명령 앞의 ``# STAGE n``, ``# MANUAL n``, ``# NOTE n`` 은 명령 기록을 구분하는 표식입니다. (``MANUAL`` 은 직접 입력한 설치·실행 명령, ``NOTE`` 는 확인용 명령입니다. 자세한 설명은 `0단계 <ch0_prerequisites.md>`__ 에 있습니다.)
