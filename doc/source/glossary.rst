용어집
============

.. glossary::

   Ansible
      인벤토리에 등록한 여러 서버에 플레이북으로 설정을 적용하는 도구입니다.

   AppArmor
      프로파일에 따라 프로세스의 파일 접근 등을 제한하는 Linux 보안 모듈입니다.

   Calico
      이 실습에서 파드 네트워크를 구성한 네트워크 플러그인입니다.

   chrony
      NTP를 사용해 호스트의 시계를 동기화하는 소프트웨어입니다.

   cloud-init
      클라우드 이미지가 처음 부팅될 때 계정, SSH 공개키, 호스트 이름 등을 설정하는 도구입니다.

   CNI
      컨테이너 런타임과 네트워크 플러그인이 통신하기 위한 규격입니다.

   containerd
      노드에서 컨테이너의 실행과 수명 주기를 관리하는 런타임입니다.

   etcd
      Kubernetes가 클러스터 상태를 보관하는 분산 키-값 저장소입니다.

   Glance
      OpenStack에서 이미지를 등록하고 조회하는 서비스입니다.

   Helm
      차트와 설정값을 이용해 Kubernetes 애플리케이션을 설치하고 업데이트하는 도구입니다.

   Ingress
      호스트 이름과 경로를 기준으로 HTTP 요청을 서비스에 전달하는 규칙을 정의하는 Kubernetes 리소스입니다. 실제 처리는 Ingress 컨트롤러가 맡습니다.

   Keystone
      OpenStack의 인증, 토큰 발급과 서비스 카탈로그를 담당합니다.

   kubectl
      Kubernetes API를 통해 클러스터 리소스를 조회하고 관리하는 명령줄 도구입니다.

   Kubernetes
      여러 노드에 컨테이너 워크로드를 배치하고 실행 상태를 관리하는 시스템입니다.

   Kubespray
      Ansible 플레이북으로 Kubernetes 클러스터를 설치하고 구성하는 프로젝트입니다.

   KVM
      Linux 커널이 CPU의 하드웨어 가상화 기능을 사용할 수 있게 하는 모듈입니다.

   libvirt
      가상 머신, 가상 네트워크, 스토리지 등을 관리하는 API와 도구를 제공합니다.

   Local Path Provisioner
      파드가 배치되는 노드의 로컬 스토리지를 이용해 볼륨을 제공하는 프로비저너입니다.

   MetalLB
      베어메탈 Kubernetes 환경에서 LoadBalancer 유형 서비스에 외부 IP를 제공하는 구현입니다.

   NAT
      패킷의 IP 주소를 변환하는 방식입니다. 이번 실습에서는 VM이 호스트를 통해 외부와 통신할 때 사용했습니다.

   Neutron
      OpenStack에서 네트워크, 서브넷, 포트 등을 관리하는 서비스입니다.

   Nova
      OpenStack에서 인스턴스 생성 요청과 컴퓨트 자원을 관리하는 서비스입니다.

   NTP
      네트워크를 통해 시스템 시계를 동기화하는 프로토콜입니다.

   OpenStack
      컴퓨트, 네트워크, 이미지 등 클라우드 인프라 서비스를 제공하는 소프트웨어입니다.

   OpenStack-Helm
      Kubernetes에서 OpenStack 서비스를 배포하기 위한 Helm 차트를 제공하는 프로젝트입니다.

   Placement
      리소스 제공자의 자원 보유량과 할당량을 추적하는 OpenStack 서비스입니다.

   PVC
      PersistentVolumeClaim의 약자입니다. 파드가 사용할 스토리지를 요청하는 Kubernetes 리소스입니다.

   QEMU
      가상 머신을 실행하는 소프트웨어입니다. 호스트가 지원하면 KVM으로 가속할 수 있습니다.

   SSH
      암호화된 연결로 원격 서버에 접속하는 프로토콜입니다. 공개키 인증에서는 서버에 공개키를 등록하고 개인키는 사용자가 보관합니다.

   StorageClass
      Kubernetes에서 볼륨을 어떤 프로비저너와 정책으로 제공할지 정의하는 리소스입니다.

   taint
      특정 파드가 노드에 배치되는 것을 제한하는 설정입니다. 파드의 toleration과 함께 사용합니다.

   Terraform
      설정 파일에 정의한 인프라 자원을 생성하고 변경하는 도구입니다.

   Terraform provider
      Terraform이 libvirt 등 대상 시스템의 API를 사용할 수 있도록 연결하는 플러그인입니다.

   tmux
      SSH 연결이 끊긴 뒤에도 서버에서 터미널 세션을 유지할 수 있는 프로그램입니다.

   VM
      가상 머신입니다. 이 실습에서는 한 물리 서버에서 VM 네 대를 Kubernetes 노드로 사용했습니다.

   네임스페이스
      클러스터 안에서 이름과 관리 범위를 구분하는 단위입니다.

   노드
      Kubernetes 클러스터를 구성하는 물리 서버 또는 가상 머신입니다.

   다이제스트
      이미지 콘텐츠를 식별하는 해시값입니다. 태그와 달리 특정 콘텐츠를 지정할 수 있습니다.

   레이블
      Kubernetes 리소스에 붙이는 키와 값입니다. 이 실습에서는 어떤 노드에 서비스를 배치할지 지정하는 데 사용했습니다.

   멱등성
      같은 작업을 반복해도 목표 상태가 유지되는 성질입니다.

   베어메탈 서버
      운영체제를 물리 하드웨어에 직접 설치한 서버입니다.

   볼륨
      저장 공간의 한 단위입니다. libvirt에서는 스토리지 풀 안에 만든 디스크 이미지 등이 해당합니다.

   스토리지 풀
      libvirt가 볼륨을 생성하고 관리하는 저장 공간입니다.

   인벤토리
      Ansible이 관리할 호스트, 그룹과 접속 정보를 정의한 목록입니다.

   차트
      Kubernetes 리소스 템플릿과 기본 설정을 함께 배포하는 Helm 패키지입니다.

   컨테이너
      격리된 실행 환경에서 애플리케이션 프로세스를 실행하는 단위입니다.

   컨트롤 플레인
      Kubernetes API, 스케줄링, 클러스터 상태 조정 등을 담당하는 구성요소입니다.

   파드
      Kubernetes가 배치하는 최소 실행 단위입니다. 하나 이상의 컨테이너가 네트워크 등을 공유합니다.

   플레이북
      Ansible이 대상 호스트에 수행할 작업을 YAML로 정의한 파일입니다.
