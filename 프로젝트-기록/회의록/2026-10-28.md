## 2. 회의 목적 및 안건

- 서버 확보 현황 및 OpenStack on Kubernetes 구축 관련 세부사항 점검&확정
    1. vm 구성안 - 컨트롤 플레인, 컨트롤 서비스용 워커, 컴퓨트 워커 
    2. 구현 도구 - Terraform+libvirt -> Ansible -> Kubespray -> Openstack-Helm
    3. 버전 - OpenStack 2026.1 Gazpacho, Ubuntu 24.04, Kubernetes 1.35, Kubespray v2.31.0
    4. 검증수준 - 배포(Pod가 running 또는 completed 인가)+서비스동작(Keystone, glance, neutron, nova, placement의 동작 및 연동 오류여부) 검증
- kit 평가 기준과 비교대상 검토
    1. 재현성
        - 숫자보다는 o/x 체크리스트로 확인하는 방식
            - 성공률: pod가 모두 정상 상태인가, 핵심 서비스가 정상 작동중인가
            - 멱등성: 재실행 시 처음 실행 결과와 다른 불필요한 변경 사항이 없는가
            - 초기화 완전성: 초기화 후 잔여물이 없는가
    2. 자동화 수준
        - 단계별로 수동 수행 시 명령 수와 키트 사용 시 수동 명령 수를 비교
        -> kit를 통해 사용자의 수동 작업이 얼마나 감소했는지를 보여주는 방식
    3. 논문 작성 진척도 및 제출 준비 현황 점검 - 초록 작성 완료
    4. 수정한 다이어그램과 WBS 검토
